2. Интерфейс программы

После запуска PCB Studio открывается главное окно приложения, в котором расположены основные инструменты для проектирования печатных плат.

  • Панель инструментов — выбор объектов, добавление компонентов, создание дорожек и отверстий, поворот и удаление элементов, отмена действий, управление сеткой и масштабом.
  • Библиотека компонентов — список доступных электронных компонентов.
  • Рабочая область платы — размещение компонентов, отверстий и дорожек.
  • Панель свойств — просмотр и изменение параметров выбранного объекта.
  • Меню проекта — создание, открытие и сохранение проекта, экспорт SVG и проверка платы.

Для выбора операции нажмите соответствующую кнопку. После этого выполняйте действие в рабочей области. Масштабирование выполняется колесом мыши с Ctrl, перемещение области — средней кнопкой мыши.
