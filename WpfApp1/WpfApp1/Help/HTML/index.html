PCB Studio — Руководство пользователя

Справочная система

Руководство описывает работу с графическим редактором печатных плат PCB Studio: создание проекта, размещение электронных компонентов, построение дорожек, добавление монтажных отверстий, проверку правил проектирования и экспорт результатов.

Выберите нужный раздел в содержании. Для вызова справки непосредственно из приложения нажмите F1 или выберите пункт меню «Справка (F1)».
