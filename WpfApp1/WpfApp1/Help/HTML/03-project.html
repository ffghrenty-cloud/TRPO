3. Создание проекта

Для начала работы с печатной платой необходимо создать новый проект.

  1. Запустите приложение PCB Studio.
  2. Выберите команду «Новый проект» в меню «Файл».
  3. В рабочей области появится новая плата.
  4. Перейдите к добавлению электронных компонентов.

Для продолжения работы с ранее созданным проектом используйте команду «Открыть проект» и выберите файл проекта с расширением .pcbproj или XML.

Рекомендуется регулярно сохранять изменения, чтобы не потерять результаты работы.
