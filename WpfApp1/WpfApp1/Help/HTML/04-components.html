4. Работа с компонентами

Библиотека содержит резисторы, конденсаторы, светодиоды, микросхемы, разъёмы, транзисторы и другие элементы.

  1. Выберите тип компонента в библиотеке слева.
  2. Нажмите «Добавить компонент на плату».
  3. Переместите указатель в нужное место рабочей области.
  4. Щёлкните левой кнопкой мыши для установки компонента.

Для перемещения компонента выберите инструмент «Выбор», выделите элемент и перетащите его. Для изменения ориентации используйте «Повернуть» или клавишу R. Для удаления выделите элемент и нажмите Delete.

Параметры обозначения, значения и координат выбранного компонента можно изменить на панели «Свойства» справа.
