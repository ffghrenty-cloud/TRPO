1. Назначение программы

PCB Studio предназначена для создания и редактирования компоновки печатной платы. Программа позволяет размещать электронные компоненты, монтажные отверстия и проводящие дорожки на рабочем поле, изменять параметры объектов, сохранять проект и экспортировать изображение платы.

Руководство относится к приложению WpfApp1. Названия элементов интерфейса могут незначительно отличаться в зависимости от версии сборки.

2. Интерфейс редактора

Главное окно содержит меню команд, панель библиотеки компонентов, рабочую область печатной платы и область свойств выбранного объекта. В нижней части окна отображается строка состояния с информацией о текущем режиме и количестве объектов.

  • Библиотека компонентов — выбор типа компонента для размещения.
  • Рабочая область — поле, на котором создаётся плата и размещаются объекты.
  • Панель свойств — просмотр и изменение параметров выбранного элемента.
  • Строка состояния — подсказки о выполняемых действиях.

3. Создание проекта

  1. Запустите PCB Studio.
  2. Создайте новый проект через меню или сочетание Ctrl+N.
  3. При необходимости настройте масштаб и отображение сетки.
  4. Разместите необходимые элементы на рабочем поле.
  5. Сохраните проект командой Ctrl+S, задав имя файла.

4. Работа с компонентами

Выберите нужный элемент в библиотеке и нажмите кнопку добавления компонента на плату. Затем укажите место размещения щелчком левой кнопки мыши по рабочей области. Для редактирования параметров выделите компонент и используйте панель свойств.

Для перемещения выберите инструмент выбора, выделите объект и перетащите его в новое положение. Для поворота используйте предусмотренную команду поворота в интерфейсе или клавишу поворота, указанную в строке состояния.

5. Дорожки и монтажные отверстия

Дорожки

Включите режим прокладки дорожек, укажите начальную точку на плате, затем конечную точку. При необходимости измените ширину дорожки и слой в панели параметров. Для выхода из режима используйте инструмент выбора.

Монтажные отверстия

Выберите команду добавления монтажного отверстия и щёлкните по месту его размещения. Диаметр задаётся параметрами инструмента/объекта. Для изменения положения используйте режим выбора.

6. Сохранение и экспорт

Сохраняйте проект сочетанием Ctrl+S. Для открытия ранее сохранённого проекта используйте Ctrl+O. Команда экспорта позволяет сформировать графическое представление платы в поддерживаемом приложением формате SVG.

Файл проекта предназначен для последующего редактирования. Экспортированное изображение используется для просмотра и передачи результата, но не заменяет исходный проект.

7. Проверка печатной платы

Перед завершением работы проверьте расположение компонентов и отверстий, отсутствие нежелательных пересечений и корректность соединений. Если в текущей сборке доступна команда DRC/проверки платы, запустите её из соответствующего пункта интерфейса и устраните выведенные замечания.

8. Горячие клавиши

  • F1 — открыть справку.
  • Ctrl+N — создать проект.
  • Ctrl+O — открыть проект.
  • Ctrl+S — сохранить проект.
  • Ctrl+E или Ctrl+P — экспорт SVG (если команда доступна в текущей сборке).
  • Esc — отменить текущее действие/режим размещения.

9. Устранение проблем

  • Справка не открывается: убедитесь, что папка Help скопирована рядом с WpfApp1.exe. Приложение сначала пытается открыть CHM, затем локальную HTML-справку.
  • Не удаётся открыть проект: проверьте, что выбран файл проекта поддерживаемого формата и у пользователя есть права на чтение.
  • Объект не перемещается: переключитесь в режим выбора и выделите объект щелчком мыши.
