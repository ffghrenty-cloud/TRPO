# Справка PCB Studio

## Подготовка файла справки

1. Откройте исходный проект справки `NewProject.hmxp` в Help & Manual.
2. Разместите подготовленные материалы в разделах:
   - Введение в программу
   - Интерфейс редактора
   - Создание проекта
   - Работа с компонентами
   - Дорожки и монтажные отверстия
   - Сохранение и экспорт
   - Проверка печатной платы
   - Горячие клавиши
3. В настройках публикации выберите формат **Microsoft HTML Help (CHM)**.
4. Укажите имя выходного файла `PCBStudio.chm` и выполните **Publish**.
5. Скопируйте полученный файл в эту папку: `WpfApp1/WpfApp1/Help/PCBStudio.chm`.

## Подключение к приложению

Проект `WpfApp1.csproj` автоматически копирует `Help/PCBStudio.chm` в выходную папку приложения под именем `PCBStudio.chm` рядом с `WpfApp1.exe`.

Открытие выполняется из пункта меню **Справка (F1)** и клавишей **F1**. Если CHM-файл ещё не опубликован или отсутствует, приложение покажет сообщение с ожидаемым расположением файла.

## Проверка

После публикации и сборки проверьте, что в папке `bin/Debug` (или `bin/Release`) находятся оба файла:
- `WpfApp1.exe`
- `PCBStudio.chm`

Запустите приложение и проверьте открытие справки через меню и клавишу F1.
