# Справка PCB Studio (проект WpfApp1)

## Что уже подключено

- `Help/index.html` — автономное руководство пользователя, открывается как резервная справка.
- `PCBStudio.chm` — необязательный скомпилированный файл Help & Manual. Если он присутствует, приложение открывает CHM вместо HTML.
- `F1` и пункт меню **Справка (F1)** вызывают один обработчик в `MainWindow.xaml.cs`.

## Как работает приложение

При нажатии F1 или выборе пункта меню приложение ищет файлы в следующем порядке:

1. `PCBStudio.chm` рядом с `WpfApp1.exe`.
2. `Help/index.html` в подпапке `Help` рядом с `WpfApp1.exe`.

Файл HTML включён в проект и автоматически копируется в выходную папку при сборке. Поэтому справка работает даже до публикации CHM.

## Как получить CHM из Help & Manual

1. Откройте `NewProject.hmxp` в Help & Manual.
2. В дереве проекта проверьте разделы руководства.
3. Откройте задачу публикации **Publish your project in CHM format**.
4. Задайте имя выходного файла `PCBStudio.chm` (в исходной конфигурации может стоять `NewProject.chm`).
5. Выполните **Publish**.
6. Скопируйте полученный файл в `WpfApp1/WpfApp1/Help/PCBStudio.chm` и пересоберите проект.

`WpfApp1.csproj` автоматически копирует CHM рядом с `WpfApp1.exe`.

## Проверка

После сборки проверьте наличие:

- `bin/Debug/WpfApp1.exe` (или `bin/Release/WpfApp1.exe`);
- `bin/Debug/Help/index.html` (или соответствующей папки Release);
- `bin/Debug/PCBStudio.chm` — только если CHM уже опубликован и добавлен в проект.

Запустите `WpfApp1.exe` и проверьте открытие справки через F1 и меню.
