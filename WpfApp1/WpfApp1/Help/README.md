# Справка PCB Studio — только CHM

Приложение **WpfApp1** открывает справку из отдельного файла `PCBStudio.chm`.

## Размещение

После публикации в Help & Manual скопируйте `PCBStudio.chm` в эту папку:

`WpfApp1/WpfApp1/Help/PCBStudio.chm`

При сборке `WpfApp1.csproj` копирует файл в выходную папку рядом с `WpfApp1.exe`.

## Открытие

- Клавиша **F1**.
- Пункт меню **Справка (F1)**.

Если CHM отсутствует, приложение показывает сообщение о том, где его разместить. HTML-страница вместо CHM не используется.

## Компиляция

1. Откройте `NewProject.hmxp` в Help & Manual.
2. Выберите задачу публикации **Publish your project in CHM format**.
3. Убедитесь, что имя результата — `PCBStudio.chm`.
4. Нажмите **Publish**.
5. Поместите созданный CHM в указанную выше папку и пересоберите WpfApp1.
