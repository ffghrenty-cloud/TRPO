# Altium-layout — учебный редактор печатных плат

WPF-приложение на C# для .NET Framework 4.8.

## Возможности прототипа

- визуальный холст платы 100 × 60 мм с сеткой;
- библиотека базовых компонентов: R, C, D, U, J и TP;
- добавление, выбор, перемещение и установка координат компонентов;
- прокладка прямых дорожек кликами по начальной и конечной точкам;
- видимость верхнего/нижнего медного слоя и шелкографии;
- сохранение и открытие проекта в XML-формате `.pcbproj`;
- базовая учебная проверка DRC;
- экспорт изображения платы в SVG.

## Запуск

1. Откройте `WpfApp1/WpfApp1.slnx` в Visual Studio, либо откройте проект `WpfApp1/WpfApp1/WpfApp1.csproj`.
2. Убедитесь, что установлен .NET Framework 4.8 Developer Pack и компонент разработки WPF для .NET desktop.
3. Выберите конфигурацию Debug и запустите проект.

## Управление

- **＋ Компонент** — добавить выбранный в библиотеке компонент.
- Щелчок по компоненту и перетаскивание — переместить его.
- **Дорожка** — два щелчка внутри платы задают начало и конец прямой дорожки.
- Колесо мыши — вертикальная прокрутка рабочей области; Shift + колесо — горизонтальная прокрутка.\n- Ctrl + колесо — плавное изменение масштаба (40–300%).\n- Средняя кнопка мыши + перетаскивание — панорамирование платы.\n- Ctrl+N — новый проект; Ctrl+O — открыть; Ctrl+S — сохранить; Ctrl+E — экспорт SVG.\n- Ctrl+0 — сброс масштаба и позиции; Delete — удалить выбранный компонент; G — сетка; T — режим дорожки; V — режим выбора; Esc — отменить текущую операцию.
- **Файл → Сохранить проект / Открыть проект** — сериализация проекта в XML.
- **Проверить DRC** — базовые проверки границ, возможных пересечений и ширины дорожек.

> DRC реализован как учебная демонстрация, а не как полноценная проверка производственной платы. SVG-экспорт также предназначен для просмотра, не является Gerber-производственным пакетом.
