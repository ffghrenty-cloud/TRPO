# Altium-layout — редактор печатных плат

WPF-приложение на C# для .NET Framework 4.8. Интерфейс и рабочий процесс развиваются по образцу PCB Layout в Proteus ARES: размещение компонентов, интерактивная трассировка, слои и проверка правил.

## Возможности

- Рабочая область платы 100 × 60 мм с переключаемой сеткой.
- Библиотека базовых условных корпусов: резистор, конденсатор, светодиод, микросхема, разъём и тестовая точка.
- Выбор, перетаскивание, точная установка координат и поворот компонентов на 90°.
- Ручная прокладка дорожек с интерактивной линией предпросмотра.
- Привязка начала/конца дорожки к контактным площадкам и сетке 0,5 мм; привязку можно отключить.
- Выбор ширины дорожки (0,25 / 0,35 / 0,50 / 0,75 мм) и медного слоя (Top / Bottom).
- Отдельное управление видимостью верхнего и нижнего медных слоёв и шелкографии.
- Панорамирование, масштабирование, горячие клавиши.
- Сохранение/открытие проекта в XML-формате `.pcbproj`.
- SVG-экспорт для визуального просмотра.
- DRC-проверки границ платы, перекрытия корпусов, минимальной ширины, длины дорожек и зазоров между дорожками одного слоя.

## Запуск

1. Откройте `WpfApp1/WpfApp1.slnx` в Visual Studio либо откройте `WpfApp1/WpfApp1/WpfApp1.csproj`.
2. Установите .NET Framework 4.8 Developer Pack и компонент разработки WPF для .NET desktop.
3. Выберите конфигурацию Debug и запустите проект.

## Управление

- **＋ Компонент** — добавить выбранный в библиотеке компонент.
- **Выбор** — щёлкните компонент и перетащите его.
- **Повернуть** — повернуть выбранный компонент на 90°.
- **Дорожка** — щёлкните начальную и конечную точки; вторая точка завершает дорожку, после чего можно начать следующую.
- **Ширина / Слой** — параметры новой дорожки.
- **Привязка** — включает привязку к контактным площадкам и сетке.
- Колесо мыши — вертикальная прокрутка; Shift + колесо — горизонтальная прокрутка; Ctrl + колесо — масштаб 40–300%.
- Средняя кнопка мыши + перетаскивание — панорамирование.
- Ctrl+N — новый проект; Ctrl+O — открыть; Ctrl+S — сохранить; Ctrl+E — экспорт SVG.
- Ctrl+0 — сброс масштаба; Delete — удалить выбранный компонент; G — показать/скрыть сетку; T — режим дорожки; V — режим выбора; Esc — отменить текущую операцию.

## Ограничения

Это развиваемый редактор-прототип, а не замена профессиональной EDA-системы. В модели пока нет электрической схемы/нетов, поэтому редактор не может достоверно строить ratsnest, проверять электрическую связность или автоматически выполнять полноценную трассировку. DRC — набор геометрических проверок, а SVG не является Gerber/Excellon-пакетом для производства. Для реального изготовления платы нужны корректные библиотеки корпусов, электрические сети, технологические ограничения и проверка производственных файлов.
