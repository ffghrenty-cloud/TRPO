# PCB Studio — новая версия приложения

Независимое WPF-приложение для Windows на .NET Framework 4.8. Проект расположен в отдельной папке `PCBStudio` и не зависит от старого `WpfApp1`.

## Возможности
- Рабочая плата 100 × 60 мм с сеткой и масштабированием колёсиком.
- Добавление резисторов, конденсаторов, микросхем, разъёмов и диодов; выбор, перемещение и поворот компонентов.
- Создание дорожек Top/Bottom с выбором ширины.
- Монтажные отверстия.
- Сохранение/загрузка проекта в XML-формате `.pcb`.
- Экспорт в SVG.
- Базовая проверка размещения DRC.
- Отмена последнего изменения (Ctrl+Z).
- Горячие клавиши: Ctrl+N/O/S/Z, V, T, H, R, Delete, Esc, F.

## Сборка
Откройте `PCBStudio.csproj` в Visual Studio на Windows с установленным .NET Framework 4.8 Developer Pack или выполните:
`msbuild PCBStudio/PCBStudio.csproj /p:Configuration=Release`

Это новая самостоятельная реализация; старый проект оставлен без удаления для сравнения и отката.
